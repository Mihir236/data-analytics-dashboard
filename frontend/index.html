Power BI Desktop

  1. Open Power BI Desktop.
  2. Click on Get Data → More....
  3. Search for ODBC and select it.
  4. Under Connection string, enter:
    Driver={SQLite3 ODBC Driver};Database=[Path_To_Project]/data/dashboard.db;
  5. Alternatively, install the official SQLite ODBC driver, create a System DSN pointing to the database, and connect using DSN.
  6. In the Navigator window, select the sales and customers tables to load them into the Power Query Editor.

Tableau Desktop

  1. Open Tableau Desktop.
  2. Under To a Server, select Other Databases (ODBC).
  3. Select Driver and choose SQLite3 ODBC Driver.
  4. Click Connect, select the database file at:
    [Path_To_Project]/data/dashboard.db
  5. Click OK and Sign In.
  6. Drag and drop the tables into the Join Canvas and configure:
    sales.customer_id = customers.customer_id (Inner/Left Join).

Pro-Tips for BI Modelling

Star Schema Setup

Set up a Star Schema relationship inside the BI Model view: sales acts as the Fact Table (containing metrics like quantity, profit, amount), and customers acts as the Dimension Table.

Export raw SQL scripts

If you prefer to load data into cloud warehouses or other engines like PostgreSQL/MySQL, you can copy the schema layout structures directly from the SQL Console catalog sidebar.
